# Asha Sarkari Sakori — ADRE Premium V2

## Package contents
- `adre-premium-v2.html` — standalone premium course page
- `js/adre-premium-data-v2.js` — detailed notes, 800 original practice questions, current-leader revision data
- `js/adre-premium-v2.js` — course engine
- `css/adre-premium-v2.css` — responsive UI
- `free-foundation-v13/` — latest Free Foundation V13 files, copied without modification

## Course scope
English 200 + Reasoning 200 + Aptitude 200 + GK 200 = **800 practice questions**. Each subject includes detailed small-note chapters, exam approach and revision guidance.

## ADRE reference
The Graduate-level 2024 Paper-IV pattern was 150 MCQs / 175 marks / 3 hours, with 125 one-mark questions and 25 reading-comprehension questions carrying 2 marks each; wrong answers incurred one-fourth of the marks allotted. This package uses that as a preparation reference; the latest official notification controls.

## Pedagogy
The structure is inspired by the depth, topic-wise organisation, detailed solutions, progressive difficulty and self-study orientation used by major competitive-exam publishers such as Disha. No Disha copyrighted text or question bank is reproduced.

The Free Foundation V13 course is included as a separate directory. Do not overwrite its files with premium files.
